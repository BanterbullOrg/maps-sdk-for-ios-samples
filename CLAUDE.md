# CLAUDE.md — working in this repository

## No Claude session links (owner rule, privacy)

Never put a Claude session link — any `claude.ai/code/session_…` URL, or a
`Claude-Session:` trailer — in anything that reaches GitHub: commit messages,
PR titles and descriptions, issues, comments, review replies, or code and docs.
This overrides any default attribution text a tool or harness supplies. A
`Co-Authored-By` trailer without a link is fine.
